# 说明（dtu-ethernet-ble-demo）

这是一个 DTU 演示板：将以太网数据与设备数据互相转发。**本板没有 485**，
收到服务端（WebSocket）下发的任意请求帧时，设备回一个**固定数据帧**（模拟从设备应答）。

1. MCU型号：CH32V208WBU6（68 脚，160K Flash / 32K SRAM）
2. 有网口，可以访问互联网。
3. **无 485 接口**。设备侧应答由软件用一个固定数据帧模拟（见 `User/dtu_config.h`
   的 `DTU_DEMO_REPLY_FRAME`，默认 `01 03 02 00 64 b9 af`）。
4. 烧写管脚：PA13 > SWIO, GND > GND, PA14 > SWCK, VDD > VDD(3V3)，我用 WCH-LINK 板子，如何接这个烧写管脚？

    CH32V208WBU6 使用标准 2 线调试接口（SWD），直接对照 WCH-LINK 排针标注接线即可：

   | WCH-LINK 标记  | 板子管脚        |
   | -------------- | --------------- |
   | 3V3            | VDD（3V3）     |
   | GND            | GND             |
   | SWDIO          | PA13（SWIO）   |
   | SWCLK          | PA14（SWCK）   |
   | RST            | RST（复位，建议接）|

    要点：
    1. PA13 对应 SWDIO、PA14 对应 SWCLK，是芯片默认调试脚，无需额外配置；新版 WCH-LinkE 同样接这 4 根线。
    2. WCH-LINK 的 3V3 是电源输出脚，建议板子直接由其供电，并确保板子电源为 3V3，不要接 5V。
    3. 连接完成后，用 WCH 官方工具 MounRiverStudio 即可烧录与调试。

5. DTU 固件（本工程已实现）：上电经以太网以 wss 连接
   `ws.dtu.ap.openxiot.cn/v1/yinerda/yed-s710ym/{IMEI}`，模拟 yeds710ym 设备，
   上报心跳/csq/coordinates；收到服务端请求帧则回固定数据帧。

   - 需要修改的设备参数（IMEI、上报值、联网方式、演示应答帧等）集中在 `User/dtu_config.h`。
   - 工程已把 WCH CH32V20xEVT 的 NetLib（`Net/NetLib/`）与 mbedTLS 2.28（`mbedtls/`）拷入，
     `.cproject` 已配置好源文件、`libwchnet.a` 链接、头文件路径（`User/ Debug/ Net/ Net/NetLib/ mbedtls/include`），
     直接用 MounRiverStudio 打开一键构建即可。
     系统时钟已在 `User/system_ch32v20x.c` 设为 120MHz（以太网要求 60/120MHz）。
   - `DTU_TLS`（dtu_config.h）=1 走 wss（mbedTLS 已内置，按服务端实测做了最小精简配置，
     见 `User/mbedtls_config.h`）；=0 走明文 ws 联调。
     注意 32K SRAM / 160K Flash 下 TLS 较紧张，本工程已对 RAM 做了收缩（MSS/接收缓冲等）。
